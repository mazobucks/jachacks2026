# jachacks2026
## Features
- Exam boss, he dies when you are fully ready for the exam
- Classes, depending on how good ur are at a subject
- levelling up
- stat points for each subject
- Exam calendars
- Study days for the calendars
- Leaderboard
- Sources for the courses (knowledge base)
- every time you do a quiz you get xp
- Status effects when on a streak (others too)
- Daily missions and training quests to earn bonus XP
- Boss raid challenges for major exams and finals
- Mastery badges for completing subjects or topics
- Guilds or party mode for team study sessions
- Goals = Quests
